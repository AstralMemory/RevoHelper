# RevoHelper
轻量、免费的机械革命笔记本第三方控制台。当前Beta下载与问题反馈，正式版将采用MIT协议开源

当前提供 **Beta v1.0.0** 公开测试版。此仓库暂时用于产品介绍、下载与问题反馈，不包含 RevoHelper 应用源码；正式版源码计划采用 MIT 许可证发布。

## 下载

前往 [Releases](https://github.com/AstralMemory/RevoHelper/releases)，下载 `RevoHelper-v1.0.0-Beta.zip`，解压后运行 `RevoHelper.exe`。

需要 Windows 11、Intel / AMD 64 位处理器，以及 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。无需安装程序本体；建议以管理员身份运行。

## 可以做什么

- 查看 CPU / GPU 状态，切换性能模式。
- 调整支持的 CPU / GPU 功耗与频率参数、自定义风扇曲线。
- 控制键盘、灯带、LOGO 和水冷灯光，连接蓝牙水冷。
- 设置显卡输出、屏幕刷新率、按键开关和开机启动。

功能按机型支持情况显示，并非所有机型都已验证。主要在开发者的机械革命 2025 款耀世机型测试，电池相关功能仍需更多反馈。

## 开发方式声明

RevoHelper 采用 Vibe Coding 方式开发，代码主要由 AI 辅助编写。开发者主要负责产品逻辑、方案与改动审批、UI 设计、实际测试和迭代改进等工作。

## 使用提醒

可以与官方控制台共存，不会停用或禁用它们。官方预设风扇曲线通常只供参考，自定义模式可以调整。超频可能导致不稳定，切换显卡输出后需保存工作并重启。

使用说明和第三方组件许可集中在运行包内的 `先阅读我-README.txt` 与 `Third-Party.txt`。
