# RevoHelper V1.0.1

本版主要修复设备识别、性能档位可用性与操作恢复问题。

## 新增

- 设置页增加“设备与功能检测”，可在官方服务恢复后重新检测设备和可用功能。
- 灰色档位按钮可悬停查看具体原因，区分正在检测、设备身份未确认、控制组件缺失和尚未收到档位信息。

## 修复

- 修复部分设备读取 BIOS、主板等信息失败时，已识别的品牌被清空、性能档位被误禁用的问题。
- 改进档位识别，兼容独立或较晚返回的模式信息；统一当前档位显示与切换结果确认，保留错误索引和自定义方案的校验。
- 修复单个异常配置文件导致其他正常方案一起无法读取的问题；基础档位识别不再依赖 CPU 功耗字段完整。
- 修复电池保护、充电上限或设备开关读取失败，连带影响 USB 关机充电、深度睡眠和快捷设置的问题。
- 修复操作错误提示被传感器更新覆盖、传感器缺失后仍显示旧读数的问题。
- 修复 FPS 自动/手动来源和所选程序在重启后未正确恢复的问题。
- 完善 CPU/GPU 参数回读与失败恢复，保留用户或其他程序的后续改动；修复动态节能与手动限频恢复记录的衔接问题。
- 修复同时启动两个实例时可能互相退出的问题。

## 优化

- 基础设备与官方功能识别先完成，可选 CPU 后端探测不再阻塞首页功能。
- 启动识别支持有限重试，官方服务重连后可重新检测；重检时保留已有参数草稿。
- 风扇状态已有有效数据时可查看曲线；修改仍需确认自定义档位与对应控制能力。
- 精简并保留局部失败反馈，长提示可悬停查看全文。

部分机型已验证支持，具体功能以机型实际支持情况为准。欢迎通过 [Issues](https://github.com/AstralMemory/RevoHelper/issues) 提供机型、Windows 版本、操作步骤和截图。
