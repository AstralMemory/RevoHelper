# RevoHelper V1.0.0

相较 Beta v1.0.0 的主要更新。产品介绍与通用使用说明请见[项目主页](https://github.com/AstralMemory/RevoHelper)。

> 本文件为本地待发布文案，不表示正式版或源码已公开。GPU 70 W 仅供机型允许时尝试，不保证本机或其他机型能达到该上限；发布前请以最终实测结果为准。

## 新增

- **外置性能监控横条**：集中显示 FPS、CPU / GPU 温度、使用率、功耗和频率，不向游戏注入代码。支持五档字号、背景不透明度、置顶、锁定和六个贴边位置预设。
- FPS 默认跟随前台程序，也可手动添加并固定来源；没有有效帧率时显示 `FPS —`。仅记录主动添加的程序，保存在本机，不展示全部窗口列表。
- 深色模式、较完整的英文界面，以及设置中的“关于与公告”。公告随版本内置，不主动弹窗或后台获取。
- GPU 功耗设置按机型当前回报提供范围，允许时可尝试 70 W；测试时先关闭 Dynamic Boost。70 W 不是通用最低值，最大功耗也因机型而异，具体以回读和实测为准。

## 修复

- 完善频率限制在操作失败、正常退出及异常恢复时的还原。
- 修复切换方案时可能混用风扇草稿或提交过期参数的问题。
- 修正 Boost 兼容处理，不擅自提高用户已有的处理器上限；临时设置按条件恢复，保留用户或其他程序的后续修改。
- 完善部分 CPU / GPU 参数写入失败后的回退，减少遗漏原参数或开关状态的风险。
- 修复 GPU 设置可能被旧回读覆盖、开关跳回的问题。TGP、Dynamic Boost 开关和瓦数独立提交；关闭 Dynamic Boost 保留开启时档位，不写 0 W，也不改动 TGP。
- 分别展示 OEM 确认设置与驱动当前上限，取消旧的功耗公式补偿和目标换算，避免把不同含义的数值混为一谈。
- 修复内置水冷启动组件与主程序启动重叠时可能互相断开连接的问题，两者使用独立连接身份。
- 改进热键确认、风扇恢复反馈及开机启动处理。

## 优化

- 调整全局字体和信息层级，让小字更清晰、信息展示更合理；不改变窗口尺寸，修正对齐及文字遮挡。
- 四个模式的小描述略微缩小、变淡，突出模式名称；“关于与公告”移除冗长、易过时的说明卡，保留版本、公告与项目入口。
- GPU 滑块松手后再提交，拖动不再逐档等待；模式切换先立即更新界面，后台核对设备结果，失败时提示并同步。
- 监控设置融入左侧信息面板，统一性能、风扇和监控的界面风格。
- 精简动态节能与设置说明，详细规则放入问号悬停提示，清理重复文案。
- 整理源码构建、重新打包及第三方许可材料，补齐与发行组件对应的源码来源。
- 按当前源码重建内置水冷启动组件，完善安装时的完整性检查，确保部署内容与主程序内嵌组件一致。

## 下载与运行

下载 `RevoHelper-v1.0.0.zip` 并解压，以管理员身份运行 `RevoHelper.exe`。需要 Windows 11 64 位及 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)，程序本体免安装。

部分机型已验证支持，具体功能以机型实际支持为准。欢迎通过 [Issues](https://github.com/AstralMemory/RevoHelper/issues) 提供机型、所用功能及结果，不要上传包含个人信息的完整系统报告。

开发与维护：Astral Memory。自有代码采用 MIT；第三方组件保留各自许可，详见运行包内的 `Third-Party.txt`。正式源码及运行包的公开状态以 GitHub 实际发布内容为准。
