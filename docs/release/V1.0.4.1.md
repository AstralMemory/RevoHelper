# RevoHelper V1.0.4.1

本次 V1.0.4.1 相较 V1.0.4，主要新增了国内加速下载，修复灯光开关显示不同步的问题，并优化了各功能页的中英文界面和深色模式。

### 新增：

## 国内加速下载

- 「关于与公告」页新增「国内加速下载」和「备用加速线路」，打不开 GitHub 时也能下载。「国内加速下载」打开第三方加速站 gh-proxy.com 的版本列表，可以自己选择版本和文件；「备用加速线路」通过 ghfast.top 直接下载最新运行包。
- 加速线路只转发 GitHub 上的文件，只在点击时打开，第三方页面上的广告与本项目无关；检查更新仍然只连接 GitHub，不经过这些服务。
- 主页的「发现新版本」和「可能有新版本」提示，点击后改为打开「关于与公告」页，可以自己选择 GitHub 或加速线路。
- 运行包同时提供固定名称的 `RevoHelper.zip`（供备用线路使用），内容与带版本号的运行包完全相同。下载后可以对照下方的 SHA256 核对文件。

### 优化与修复：

## 灯光

- 修正灯带、LOGO 等灯区开关后，界面上的开关不跟着变化、甚至被拨回原位的问题。原因是灯带回复的状态慢一拍，每次读到的都是这次操作之前的状态。现在回读不一致时会稍等并再查询几次（只查询，不重复发送命令），确认后才显示结果；之后收到的灯光状态也能纠正开关显示。
- 键盘灯光方案的按钮改为左对齐，标题和说明不再错位。

## 英文界面

- 补全约 280 条状态提示的英文，涵盖灯光、电源、水冷、显示、性能、风扇等页面的回读结果和错误提示，英文界面不再夹杂这些中文提示。
- 缩短键盘灯光方案等处的英文说明，避免文字被裁切或在单词中间断行。

## 电源

- 修正「深度睡眠」时长显示为「30 mi」的问题，中文界面显示为「30 分钟」。
- 修正部分机型的电源设置之间出现两条分隔线的问题。
- 较长的说明文字会自动换行，不再被裁切。

## 其它功能页

- 显示页的 COLOR 色块改为圆角，与其它卡片一致。
- 设置页的官方控制台名称、其它页的定时关机说明可以换行，不再被裁切。
- 性能监控页的说明改为「没有可测画面时 FPS 显示为“—”」，表述更清楚。

## 深色模式

- 修正深色模式下浅色卡片里的文字和按钮看不清的问题，例如灯光页的「键盘与灯带自动熄灯」和水冷页的「登录前自动连接」。这类卡片里的按钮、下拉框和文字现在统一使用浅色样式。
