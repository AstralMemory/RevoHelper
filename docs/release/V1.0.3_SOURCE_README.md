# RevoHelper V1.0.3 Source Code

本包为 RevoHelper V1.0.3 源码，文件版本 1.0.3.9。自有代码采用 MIT 许可，第三方组件的许可见 LICENSE、THIRD_PARTY_NOTICES.md 和 Third-Party.txt。

运行需要 Windows 11 x64 和 .NET 10 Desktop Runtime。使用说明见 docs/release/V1.0.3_USER_README.txt，更新日志见 docs/release/V1.0.3.md。

构建需要 .NET 10 SDK；部分打包测试需要 PowerShell 7。

```powershell
dotnet restore RevoHelper.sln
dotnet build RevoHelper.sln -c Release
dotnet test RevoHelper.sln -c Release
dotnet publish src/RevoHelper.App/RevoHelper.App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o artifacts/publish-v1.0.3
```

本包不包含本地诊断、个人配置或真实硬件会话记录。功能与兼容性以实际设备为准。
