RevoHelper V1.0.5
2026-11-13 · 文件版本 1.0.5.9

运行
1. Windows 11 64 位（x64）及 .NET 10 Desktop Runtime：
   https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0
   请选择 Desktop Runtime，而不是普通 Runtime。运行软件不需要 PowerShell。
2. 从托盘真正退出旧版 RevoHelper，再将运行包解压至独立目录，
   以管理员身份运行 RevoHelper.exe。不要直接在 ZIP 内运行。
   已开启的开机自启会在打开新版时自动改到当前版本；确认新版正常后，
   可以删除旧版本，个人设置会保留。
3. 保留现有版本与用户设置。仅下载文件或解压不会启用限充，
   本包不自动安装限充服务或计划任务，也不自动上传诊断资料。

检查更新
- 启动约2分钟后读取 GitHub 上最新正式版的版本号；成功后每天最多
  检查一次，失败时约3小时后重试。请求不带账号信息，不发送设备、
  硬件或使用数据，也不下载、安装或运行任何内容。
- 有新版本时，主页版本号旁会出现提示，点击打开“关于与公告”页，
  可选择 GitHub 下载或国内加速线路，是否更新由你决定。
  版本号旁的刷新图标可以随时手动检查。
- “加速线路 1”和“加速线路 2”都打开第三方加速站的版本列表，可自己
  选择版本和文件。不同网络下不一定都能打开，可逐个尝试。两者都转发
  GitHub 上的文件，只在点击时打开，第三方页面上的广告与本项目无关，
  检查更新不经过这些服务。下载后可对照更新日志中的 SHA256 核对。
- 部分网络无法连接 GitHub，检查失败不影响其它功能。当前版本使用
  满15天且一直没能连上 GitHub 时，会提示一次“可能有新版本”。
- 在“设置 → 更新”可关闭自动检查，关闭后程序不会自动联网。

充电上限：默认关闭，手动选择
- 使用开关及 60% / 80% / 100% 三档。选择数值不代表已经生效，
  请同时查看状态、是否充电及充电功率。切换或恢复可能需要15–30秒。
- 不按型号、BIOS/EC版本或固定EC项目号预先拒绝，可手动尝试；
  不保证每台实际生效。仍保留必要协议、原值、回读及恢复检查。
- 点击开启后立即显示开启意图，处理期间控件灰显加载；
  这不是实际停充已经完成的证明，最终请看状态与充电功率。
- 100%会先解除已有覆盖并确认恢复，再按原生策略充电；
  不向固件写入100作为限充阈值。关闭开关则退出本功能。
- 限充不会把已经高于目标的电量主动放掉。比如95%时启用60%，
  成功停充后仍可显示95%，而不是立即变为60%。

后台保持、电源变化与开机接续
- 手动成功开启后，最小化、X隐藏到托盘及普通界面操作不会关闭限充。
  真正退出程序会停止并尝试恢复原值。
- 拔电或睡眠时先安全暂停、恢复原值，状态显示暂停/等待。重新接电或
  唤醒后，在原会话恢复已确认、电源稳定且没有异常时继续限充，
  不代表暂停期间仍在限充。
- 开启后会记住所选档位。下次打开 RevoHelper（包括开机自启）时，
  先核对并恢复上次留下的状态，再自动开启同一档位。恢复未确认时
  不会开启，请使用恢复按钮。
- Windows 关机时保持限充，不拔电源的情况下关机期间不会充到满电。
  断电后再来电时固件会自行重置，RevoHelper 未运行就不会限充，
  开机后才会接续。
- 手动关闭开关会清除记住的档位，之后不再自动开启。电池供电时启动
  只做恢复，接上电源后再自动开启。

风险与恢复
- 60%与80%仍通过共享平台状态实现，可能连带影响风扇、功耗、
  性能档位、按键及其他固件分支。普通设置操作不再预先关闭限充，
  但若真实平台或阈值被外部修改，健康检查仍会停止并尝试恢复，
  不会与官方控制台或其他软件反复抢写。
- 不刷固件、不主动直接写持久化存储、不关闭系统安全设置；
  固件仍可能自行保存阈值，不能保证零风险或全部副作用可恢复。
- 耀世开发机已有60%停充、低于80%继续充电及恢复后复充的实测。
  其他机器、完整跨阈值、长期及异常掉电行为不因开放尝试而获得验证。
- 出现“待恢复”/RecoveryPending时，保留本地恢复会话，先使用
  恢复按钮并确认状态。不要删除
  %LOCALAPPDATA%\RevoHelper\ExperimentalCharge
  下的会话记录，也不要用强杀进程代替恢复。

水冷
- 接上电源时会自动尝试连接已保存的水冷设备，可在水冷页关闭自动连接。
- 智慧控制独立开关；关闭后可用四档手动滑条，并保留上次手动档。
- 本次运行中曾确认连接成功的设备意外断开后，记忆10分钟，
  每次至少间隔3秒异步尝试连接同一已保存设备，不持续扫描蓝牙。
- 主动断开、换设备、注水/重设、关闭自动连接或退出会取消当前
  重连机会。不会为未知设备自动扫描、选择或连接。
