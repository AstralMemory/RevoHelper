## 运行与功能边界

运行需要Windows 11 x64与.NET 10 Desktop Runtime。用户操作说明见 `docs/release/V1.0.2_USER_README.txt`，更新日志见 `docs/release/V1.0.2.md`。

限充默认关闭，不保存跨进程开启状态。不再读取SMBIOS或EC项目号/版本筛选机型，不按型号预先拒绝，可手动尝试；不保证每台实际生效。仍要求固定WMI协议签名、唯一激活的logical0接口路线，以及必要控制原值、单字节写入、所有权、回读与恢复条件。100%先确认解除已有覆盖，再按原生策略充电，不将100写入固件阈值。

点击开启后立即显示开启意图，处理期间控件灰显加载；开关显示开启不等于实际停充已经完成，最终以状态、充电标志及功率观察为准。

新会话快照以可选`InterfaceInstanceName`记录选中的WMI实例路线与原始控制值。恢复使用`VerifySessionOrigin(original)`核对该路线，再检查必要现值与恢复所有权；不依赖完整电池遥测快照，也不盲扫或改用其他实例。旧会话缺少该字段时仅按已知旧版`1_0`路线兼容处理。

`SessionChargeController`只维护本进程内成功手动开启后的意图：拔电/睡眠先暂停并恢复原值，接电/唤醒后须确认恢复、稳定AC及意图未被取消，才尝试恢复目标。暂停时逻辑开关开启不代表硬件仍在限充。最小化及托盘隐藏不主动中断；手动关闭、手动恢复、真正退出、健康失败清除意图，不无限自动重试，不在下次启动自动启用。

硬件通道、独立guardian/worker、必要写入范围、所有权检查和健康停止保持独立，不另设固定机型身份门槛。真实外部平台变化、通信故障或恢复待确认不能因“持续限充”要求被忽略。平台覆盖可能影响其他固件分支，固件可能自行保存阈值；短时实测或模拟测试不证明长期安全、完整跨阈值或全部副作用可恢复。

## 构建与聚焦测试

构建需要Windows x64、.NET 10 SDK；`global.json`使用10.0.100及latestFeature滚动策略。打包及部分包装测试需要PowerShell 7，运行产品限充不依赖PowerShell。

```powershell
dotnet restore RevoHelper.sln
dotnet build src/RevoHelper.App/RevoHelper.App.csproj -c Release -p:Version=1.0.2 -p:AssemblyVersion=1.0.2.0 -p:FileVersion=1.0.2.5 -p:InformationalVersion=1.0.2+20261030
dotnet test tests/RevoHelper.Core.Tests/RevoHelper.Core.Tests.csproj -c Release --filter "FullyQualifiedName~LiquidCooling"
dotnet test tests/RevoHelper.Hardware.Windows.Tests/RevoHelper.Hardware.Windows.Tests.csproj -c Release --filter "FullyQualifiedName~BatteryCharge"
dotnet test tests/RevoHelper.App.Tests/RevoHelper.App.Tests.csproj -c Release --filter "FullyQualifiedName~Charging|FullyQualifiedName~ExperimentalCharge|FullyQualifiedName~LiquidCooling"
dotnet publish src/RevoHelper.App/RevoHelper.App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:Version=1.0.2 -p:AssemblyVersion=1.0.2.0 -p:FileVersion=1.0.2.5 -p:InformationalVersion=1.0.2+20261030 -o artifacts/publish-v1.0.2
```

这些聚焦测试用于协议、序列化、内存fake、恢复与界面回归；不应启动真实限充会话或修改实机设置。测试通过不等于有权进行固件实验，也不替代具体机型实测。完整离线测试可另运行 `dotnet test RevoHelper.sln -c Release`；历史公开打包固定输入按原路径保留，不能当成本版操作说明。

BootWater源码及已有嵌入产物均在包内。只有修改这个可选组件后才需先重新发布并替换嵌入物，再构建主程序：

```powershell
dotnet publish tools/RevoHelper.BootWater/RevoHelper.BootWater.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o artifacts/bootwater
Copy-Item artifacts/bootwater/RevoHelper.BootWater.exe packaging/BootWater/RevoHelper.BootWater.exe
```
