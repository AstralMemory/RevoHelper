RevoHelper V1.0.1
先阅读我 - README

轻量、免费、开源的机械革命笔记本第三方控制台。
项目与公开版本：https://github.com/AstralMemory/RevoHelper

运行与升级
1. 需要 Windows 11 64 位（x64）和 .NET 10 Desktop Runtime。
   官方下载：https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0
   请选择 Desktop Runtime，普通 Runtime 不能代替桌面运行时。
2. 先从系统托盘退出旧版，再解压并以管理员身份运行 RevoHelper.exe。
   关闭主窗口会缩至托盘。请勿从压缩包内运行或同时启动两个版本。
3. 本版沿用 %LOCALAPPDATA%\RevoHelper 中的设置，不需要重置。
   如需备份，请在退出所有实例后复制该目录；有恢复失败提示时保留恢复记录。
4. 已启用随 Windows 启动时，移动 EXE 后手动运行一次可更新已有启动路径。

使用提醒
- 档位按钮灰色时可悬停查看原因，并使用首页“重新检测”。请先确认官方控制台及其服务可用。
- 部分机型已验证支持；具体功能依设备实际返回的能力显示。
- 可以与官方控制台共存；同时修改同一设置时，以设备实际生效的结果为准。
- 官方预设风扇曲线通常只供参考，自定义模式可在确认支持后调整。
- 切换显卡输出前保存工作，之后手动重启；程序不会自动重启电脑。
- 功耗和频率调整以设备回读与实际负载为准。本版不包含 GPU 功耗解锁。
- 手动限频正常退出时尝试恢复；异常退出后由下次启动尝试恢复。
- 性能监控不向游戏注入代码，仅保存主动添加的程序记录。
