# RevoHelper V1.0.4.1 Source Code

本包为 RevoHelper V1.0.4.1 源码，文件版本 1.0.4.10。自有代码采用 MIT 许可，第三方组件的许可见 LICENSE、THIRD_PARTY_NOTICES.md 和 Third-Party.txt。

运行需要 Windows 11 x64 和 .NET 10 Desktop Runtime。使用说明见 docs/release/V1.0.4.1_USER_README.txt，更新日志见 docs/release/V1.0.4.md。

构建需要 .NET 10 SDK。打包脚本可以用 Windows PowerShell 5.1 或 PowerShell 7 运行；第三方声明的离线测试需要 PowerShell 7。

```powershell
dotnet restore RevoHelper.sln
dotnet build RevoHelper.sln -c Release
dotnet test RevoHelper.sln -c Release
dotnet publish src/RevoHelper.App/RevoHelper.App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o artifacts/publish-v1.0.4.1
```

程序唯一的联网代码在 `src/RevoHelper.App/Updates`：只读取 GitHub 上最新正式版的版本号，不带账号信息，不发送设备数据，也不下载、安装或运行任何内容。

本包不包含本地诊断、个人配置或真实硬件会话记录。功能与兼容性以实际设备为准。
