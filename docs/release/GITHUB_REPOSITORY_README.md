# RevoHelper

轻量、免费的机械革命笔记本第三方控制台。集中管理常用设置，让状态更清晰、调节更直接。

开发与维护：**Astral Memory**。

> 此为 V1.0.0 本地主页文案，尚未代表正式版或源码已经公开；公开状态以仓库和 Releases 为准。整理 GitHub 时保留现有产品预览图，不用这份文字稿覆盖图片资源。

## 下载

前往 [Releases](https://github.com/AstralMemory/RevoHelper/releases) 选择已公开的版本。正式版运行包名为 `RevoHelper-v1.0.0.zip`，解压后运行 `RevoHelper.exe`；不要把 GitHub 自动生成的 Source code 压缩包当作程序下载。

需要 Windows 11、Intel / AMD 64 位处理器，以及 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0)。无需安装程序本体；建议以管理员身份运行。

## 可以做什么

- 查看 CPU / GPU 状态，切换性能模式。
- 使用外置性能监控横条显示 FPS、温度、使用率、功耗和频率；支持置顶、锁定、贴边与字号设置，不向游戏注入代码。
- 调整支持的 CPU / GPU 功耗与频率参数、自定义风扇曲线。
- 控制键盘、灯带、LOGO 和水冷灯光，连接蓝牙水冷。
- 设置显卡输出、屏幕刷新率、按键开关和开机启动。
- 使用深色或浅色界面、中英文界面，以及可选的动态节能。

部分机型已通过开发者实测或用户反馈验证，具体功能以机型实际支持为准，并非所有机型的全部功能都已验证。电池保护模式不等于手动指定充电百分比，实际停止充电的行为仍需机型验证。

GPU 功耗按机型实时范围调整，TGP、Dynamic Boost 开关和瓦数独立设置；程序分别报告 OEM 设置与驱动当前上限。70 W 仅供尝试，不保证所有机型支持，也不能凭设置回读代替负载实测。

## 开发方式声明

RevoHelper 采用 Vibe Coding 方式开发，代码主要由 AI 辅助编写。开发者主要负责产品逻辑、方案与改动审批、UI 设计、实际测试和迭代改进等工作。

## 使用提醒

可以与官方控制台共存，不会停用或禁用它们。官方预设风扇曲线通常只供参考，自定义模式可以调整。超频可能导致不稳定，切换显卡输出后需保存工作并重启。

使用说明和第三方组件许可集中在运行包内的 `先阅读我-README.txt` 与 `Third-Party.txt`。

BootWater 水冷启动组件已内置，无需单独下载；登录前连接为可选功能，仅在用户主动安装时部署。组件与主程序使用独立连接身份，避免启动重叠时互相断开连接。
