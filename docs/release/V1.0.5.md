本次 V1.0.5 相较 V1.0.4.1，主要修复充电上限在开机后可能存在未接续的问题，此外新增来电后自动连接水冷设备，并修复独显无法休眠、限充无法开启、显卡输出显示不符和部分键盘灯速度相反等问题。

### 新增：

## 充电上限会记住，开机后自动接续

- 开启充电上限后，RevoHelper 会记住你选的档位。下次打开 RevoHelper（包括开机自启）时，会先核对并恢复上次留下的状态，再自动开启同一档位，不需要再点「重试恢复原值」，也不需要重新打开开关。
- 修正开着限充关机后，下次开机开关变灰、必须手动恢复才能再开启的问题。
- 关机时保持限充：不拔电源的情况下，关机期间不会充到满电。
- 手动关闭开关后不再自动开启。电池供电时启动只做恢复，接上电源后再自动开启。
- 断电后再来电（拔掉电源再插回、插座断电）时，固件会自行重置，这时如果 RevoHelper 没有运行就不会限充，开机后才会接续。这是固件的行为，软件无法改变。

## 来电后自动连接水冷

- 接上电源时，会自动尝试连接已保存的水冷设备，不用再手动点连接。可在水冷页关闭自动连接。

## 加速下载改为两条线路

- 「关于与公告」页的两个加速按钮改为「加速线路 1」和「加速线路 2」，分别打开第三方加速站 gh-proxy.com 和 gh-proxy.org 的版本列表，可以自己选择版本和文件。
- 加速站由第三方提供，不同网络下不一定都能打开，可以逐个尝试；都打不开时仍可从 GitHub 下载。
- 本版仍附带固定名称的 `RevoHelper.zip`（内容与运行包相同），供 V1.0.4.1 的「备用加速线路」按钮更新使用；从下一版起不再提供。

### 优化与修复：

## 独显休眠

- 修正 RevoHelper 运行时独显无法休眠、空闲功耗一直停在二十多瓦的问题。原因是程序每秒向 NVIDIA 驱动读取一次状态，每次读取都会被驱动当成有程序在使用显卡。
- 现在先向 Windows 询问独显是否通电，这个询问不会唤醒显卡。独显休眠时不再读取，主页显示使用率 0%、功耗 0 W、温度 N/A。
- 独显通电但空闲约 10 秒后，会暂停读取 15 秒，让它有机会休眠；这 15 秒内显示的是暂停前的读数。独显直连或外接显示器接在独显上时，读取基本照常。

## 充电上限

- 修正部分机器开启限充时提示「原始状态0x07B9已改变；不接管已有设置」的问题。其它工具留下的限充数值现在会被记为原值：开启时改为 60% 或 80%，关闭或退出时写回原来的数值。
- 无法开启时，提示里会写出读到的实际数值，方便反馈。

## 显卡输出

- 修正切换显卡输出后「关机再开机」，实际没有切换、界面却显示已切换的问题。开着 Windows 快速启动时，关机再开机不算重启，切换不会生效。
- 现在会对比内屏实际由哪块显卡驱动。设置还没生效时，显示「已设置为…，尚未生效，请点重启」。

## 灯光

- 修正键盘灯速度方向相反的问题：现在 4 最快、1 最慢。
- 修正「默认背光」点了没有反应的问题：现在恢复官方默认灯效（彩虹、亮度 3、速度 2）。

## 主页

- 修正 Core Ultra 处理器的核显「Intel Arc Graphics」被标成「独立」的问题。
