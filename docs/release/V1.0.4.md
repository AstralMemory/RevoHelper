# RevoHelper V1.0.4

本次是 V1.0.3 之后的维护更新，主要修正更新版本后开机自启可能失效的问题，让连续切换性能模式和调整灯光响应更快，修正切换后可能残留频率上限的问题，调整了主页功能入口的样式，新增新版本提醒，并整理了切换和灯光相关的代码。

### 新功能：

## 新版本提醒

- 有新版本时，主页版本号旁会出现「发现新版本」，点击打开 GitHub 下载页。不会弹窗，也不会自动下载或安装。
- 软件启动约 2 分钟后检查。检查成功后每天最多检查一次；失败时约 3 小时后重试，方便开机后才连上网络的情况。常驻托盘时也会按时检查。检查时只读取 GitHub 上最新正式版的版本号，不发送设备信息。
- 版本号旁新增刷新图标，可以随时手动检查，结果显示在主页底部；「关于与公告」页也可以手动检查。
- 部分网络无法连接 GitHub，这时检查会失败，但不影响其它功能，也不会弹出提示。如果当前版本已使用 15 天，且这段时间一直没能连上 GitHub，主页会提示一次「可能有新版本」，点击后这个版本不再提示。
- 可以在「设置 → 更新」关闭自动检查，关闭后软件不会自动联网，主页也不再显示自动提醒。

### 优化与修复：

## 开机自启

- 修正更新版本后，开机自启仍指向旧版本的问题：旧版本还在时会启动旧版本，旧版本删除后不会启动。现在打开新版本时，已开启的开机自启会自动改到当前版本。
- 已关闭的开机自启不会被重新打开；打开较旧的版本时，也不会把开机自启改回旧版本。

## 性能模式与频率控制

- 连续切换档位时响应更快。新的选择会立刻结束上一次切换后的等待，不必等它结束才开始切换；正在进行的硬件写入不会被打断。
- 修正部分设备连续切换档位时，可能残留上一档位频率上限的问题。现在切换后会先同步频率，再进行复查。
- 通过 Fn 键或官方控制台切换档位后，如果频率被覆盖并重新写入，现在会回读确认；无法确认时如实提示。
- 切换失败恢复时，不再重复发送相同的模式命令，Boost、功耗和频率仍会恢复。如果恢复到的档位或子策略与切换前不一致，会再次恢复到切换前的状态。

## 灯光

- 重新设计灯光页：灯效改成可以直接点击的方块，常用操作放在前面，键盘方案和自动熄灯移到下方。
- 亮度、速度和运行方向只在当前灯效用得上时显示。水冷灯不再显示没有作用的亮度和速度。
- 操作更跟手：等待硬件回读时控件不再变灰，可以继续调整；连续调整时只发送最新的选择。
- 键盘、灯带和水冷灯各自写入，一个灯区较慢时不再拖慢其它灯区。灯带和 LOGO 共用硬件，仍依次写入。
- 打开灯光页时，每个灯区读到就显示，不再等所有灯区都回应。
- 修正灯效已经生效，却提示「回读未匹配，未确认生效」的问题。现在灯效和开关确认后即视为成功；亮度、速度、方向或颜色没有回读确认时会单独说明。灯效本身未生效时，提示会变红。
- 运行方向显示为中文；Impact 灯效的中文名改为「冲击」；修正英文界面「Brightness」被滑块遮挡的问题。

## 主页

- 调整主页下方七个功能入口的样式：改用和设备信息栏相同的底色和边框，图标去掉内层边框并略微放大。
- 入口的中文标题不再显示为粗体，七个入口的标题字号统一。
- 「其它」入口补上说明文字，位置与其它入口对齐。
- 缩短部分英文说明，避免文字贴近边框。

## 界面反馈

- 修正启动或同步档位后，主页可能显示「界面预览已切换 · 未向硬件发送指令」的问题。这句提示现在只在手动预览时出现。
- 「关于与公告」页的「开发者公告」改为「产品介绍」，项目网址可以选中复制。

## 代码整理

- 清理不再使用的状态和重复逻辑，并将性能切换和灯光代码分别独立成单独的文件，便于后续维护。这部分不改变功能。

## 当前已知情况

- 切换失败时的恢复改动目前只经过离线测试，尚未在真机上触发验证。
- 仍有部分性能模式切换失败的问题在调查中，包括开机后需手动重启 Intel 平台服务才能恢复的反馈；本次不代表所有切换故障都已解决。
- 狂暴模式下，静音和高能都未开启时，界面目前仍显示为静音。
- LOGO 灯只回报开关和亮度，灯效是否生效需要以实际灯光为准。
- 当前没有 2023 极光实机，对该机型的改善仍待用户实际确认。
- AMD CPU 读取改动仍待 AMD 设备实测；Radeon 610M 核显读数全部为 `N/A` 的问题尚未解决。
