# RevoHelper V1.0.4

本次 V1.0.4 相较 V1.0.3，主要重构了灯光功能逻辑、调整了部分主页UI界面、新增新版本提醒、修复更新版本后开机自启可能失效的问题，并提升了连续切换性能模式的响应速度。

### 新增：

## 新版本提醒

- 从本版本开始，有新版本时主页版本号旁会出现「发现新版本」，点击打开 GitHub 下载页。只做提醒，不弹窗，也不会自动下载或安装。
- 启动约 2 分钟后检查一次，成功后每天最多检查一次；失败时约 3 小时后重试，常驻托盘时也会按时检查。检查时只读取 GitHub 上最新正式版的版本号，不发送设备信息。这是 RevoHelper 唯一的联网功能。
- 版本号旁新增刷新图标，可随时手动检查，结果显示在主页底部；「关于与公告」页也可以手动检查。
- 部分网络无法连接 GitHub，检查失败不影响其它功能，也不会弹出提示。若当前版本已使用 15 天且一直没能连上 GitHub，主页会提示一次「可能有新版本」，点击后本版本不再提示。
- 可在「设置 → 更新」关闭自动检查，关闭后产品依旧不会自动联网。

### 优化与修复：

## 灯光

- 重构灯光功能：灯效改为可直接点击的方块，常用操作放在前面，键盘方案和自动熄灯移到下方；亮度、速度和运行方向只在当前灯效用得上时显示，水冷灯不再显示没有作用的亮度和速度。
- 操作更跟手：等待硬件回读时控件不再变灰，可以继续调整；连续调整时只发送最新的选择。
- 键盘、灯带和水冷灯各自写入，一个灯区较慢时不再拖慢其它灯区；打开灯光页时，每个灯区读到就显示。
- 修正灯效已经生效，却提示「回读未匹配，未确认生效」的问题。现在灯效和开关确认后即视为成功，其它参数未回读确认时单独说明；灯效本身未生效时，提示会变红。
- 运行方向改为中文显示；Impact 灯效的中文名改为「冲击」；修正英文界面「Brightness」被滑块遮挡的问题。

## 主页

- 调整下方七个功能入口的样式，与上方设备信息栏统一底色和边框，图标去掉内层边框并略微放大。
- 入口的中文标题不再显示为粗体，七个入口字号统一；「其它」补上说明文字并与其它入口对齐；缩短部分英文说明，避免文字贴近边框。
- 修正启动或同步档位后，主页可能显示「界面预览已切换 · 未向硬件发送指令」的问题。
- 「关于与公告」页的「开发者公告」改为「产品介绍」，项目网址可以选中复制。

## 开机自启

- 修正更新版本后开机自启仍指向旧版本的问题：旧版本还在时会启动旧版本，删除后则不再启动。现在打开新版本时，已开启的开机自启会自动改到当前版本。
- 已关闭的开机自启不会被重新打开；打开较旧的版本时，也不会把开机自启改回旧版本。

## 性能模式与频率控制

- 连续切换档位时响应更快：新的选择会立刻结束上一次切换后的等待，正在进行的硬件写入不会被打断。
- 修正部分设备连续切换档位时，可能残留上一档位频率上限的问题。现在切换后会先同步频率，再进行复查。
- 通过 Fn 键或官方控制台切换档位后，若频率被覆盖并重新写入，现在会回读确认；无法确认时如实提示。
- 切换失败恢复时，不再重复发送相同的模式命令，Boost、功耗和频率仍会恢复；若恢复后的档位或子策略与切换前不一致，会再次恢复。
- 修正狂暴模式下静音和高能都未开启时，界面仍显示为静音的问题。现在只选中狂暴主卡，两个策略都不高亮，托盘菜单也不再勾选「狂暴 · 静音」。
- 整理性能切换和灯光相关代码，清理不再使用的状态和重复逻辑，不改变功能。

## 硬件信息

- 修正 Radeon 610M、780M 等 AMD 核显在主页被识别为未知显卡、读数全部显示为 `N/A` 的问题。现在会正确识别为核显并显示读数；温度与 Intel 核显一样沿用 CPU 温度，功耗和频率能否读取取决于 AMD 驱动，欢迎 AMD 机型用户反馈实际效果。
