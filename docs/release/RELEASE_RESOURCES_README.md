# RevoHelper V1.0.0 本地发布资源

这里是正式版与 MIT 开源的本地准备材料，不表示已经上传或公开。作者/维护者署名为 Astral Memory，MIT 版权年份为 2026。

## 文件说明

- `RevoHelper-v1.0.0.zip`：供普通用户下载的运行包。
- `RevoHelper`：同一份解压后的运行目录，可以从这里手动体验。
- ZIP 内只有 `RevoHelper.exe`、`先阅读我-README.txt`、`Third-Party.txt` 三个文件。说明和第三方声明请保留，实际运行不需要单独的 BootWater 文件夹。
- `RevoHelper-v1.0.0-source.zip`、`RevoHelper-source`：对应源码及重新构建、测试和打包所需资源。内嵌的第三方二进制保留来源、许可与对应源码材料；不是整个开发工作区的副本。
- `GitHub发布文案.md`、`GitHub主页README.md`：本地文字稿。主页负责介绍产品，Release 重点写新增/修复/优化；上传前按实测与最终公开状态调整。
- `内部发布检查.md`：仅供作者验收，不纳入公开源码或运行 ZIP。
