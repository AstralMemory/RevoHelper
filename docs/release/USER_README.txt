RevoHelper V1.0.0
先阅读我 - README

免费的第三方机械革命笔记本控制台。程序本体免安装，BootWater 水冷启动组件已内置。
开发与维护：Astral Memory。自有代码采用 MIT 许可证，第三方组件保留各自许可，详见 Third-Party.txt。
下载与源码获取请以 GitHub 项目页面为准。

开发方式声明
RevoHelper 采用 Vibe Coding 方式开发，代码主要由 AI 辅助编写。开发者主要负责产品逻辑、方案与改动审批、UI 设计、实际测试和迭代改进等工作。

首次使用
1. 支持 Windows 11，Intel / AMD 64 位（x64）。需要 .NET 10 Desktop Runtime，不是普通 .NET Runtime。
   官方下载：https://dotnet.microsoft.com/zh-cn/download/dotnet/10.0
2. 解压后，以管理员身份运行 RevoHelper.exe。不要在压缩包内直接运行。
3. 开机启动可在“设置”中开启。移动或改名后，请手动运行一次以更新启动路径。
4. 如需登录前连接水冷，先在“水冷”中选择并记住设备，再点击“登录前自动连接”的“安装 / 修复”。该可选功能会按需部署组件到系统目录，请重启验证。

使用前请看
- 可以与官方控制台共存，不会停用或禁用它们。两边同时操作时，以实际生效的设置为准。
- 官方的预设通常无法调整风扇曲线，所以仅作参考；请切换至自定义模式后调整。
- 切换显卡输出模式后，需保存工作并自行重启电脑。
- 超频可能导致不稳定，请从小幅调整开始。核心偏移不建议超过 300 MHz，显存偏移不建议超过 1000 MHz。
- Dynamic Boost 控制显卡可用的额外功耗，不代表实际耗电。
- GPU 滑块拖动时只预览，松手后提交。TGP、Dynamic Boost 开关与瓦数分别调整，不会改一项就顺带重写其他项。
- 关闭 Dynamic Boost 会保留开启时的瓦数档位，便于下次恢复；不会写入 0 W，也不会顺带修改 TGP。
- 切换性能模式时界面立即响应，设备在后台切换；失败或实际状态不一致时会提示并同步回已确认状态。
- 手动 CPU 频率限制在程序运行期间生效，正常退出时恢复；异常退出由下次启动尝试恢复。
- 关闭主窗口会保留托盘运行；完整退出请使用托盘菜单的“退出”。

性能监控
首页的“性能监控”可显示 FPS 和 CPU / GPU 状态。小横条可置顶、锁定、贴边，支持五档字号和背景不透明度。
默认跟随前台程序，也可手动添加并固定程序；没有有效帧率数据时显示 FPS —。不向游戏注入代码。

显卡功耗调整与验证
1. 调节范围以机型当前回报为准，70 W 只是可尝试的目标，不是所有设备通用的最低值；175 W 等上限也不是通用值。
2. 保存当前设置，在自定义模式的 GPU 设置中关闭 Dynamic Boost；如机型范围允许，可尝试把 TGP 调至 70 W。
3. 程序分别显示 OEM 确认的设置与驱动当前功耗上限，两者不能混为一谈。等待操作反馈；失败时按提示处理，不要只看滑块认定已生效。
4. 用原来的游戏或负载测试，观察显卡功耗、频率、帧率和稳定性。功耗上限不是实际耗电，轻负载低于 70 W 不能证明限功耗有效。本机能否达到该上限仍需用户真机确认。
5. 完成后可分别恢复原先的 TGP、Dynamic Boost 开关和瓦数。程序不会通过改动另一项功耗设置来补偿目标，也不会把回读数值换算成另一个目标。

兼容性与反馈
部分机型已通过开发者实测或用户反馈验证，具体功能以机型实际支持为准，不保证所有机型的全部功能可用。
电池保护模式不等于可手动指定充电百分比，实际停止充电的行为由机型决定，仍需要更多验证。
遇到问题时，请提供机型、Windows 版本、复现步骤和截图，不要上传含个人信息的完整系统报告。
