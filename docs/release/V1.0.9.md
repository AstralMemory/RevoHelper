本次 V1.0.9 相较 V1.0.8，修复了开机自启打不开的问题，改进了关机时的限充保持和电脑唤醒后的官方托盘检测，移动程序文件后限充和开机自启也能照常工作。

### 修复：

## 开机自启

- 在从没开过开机自启的电脑上，打开“跟随 Windows 启动”会提示“读取启动项原配置失败，系统找不到指定的文件 (0x80070002)”，开关一直打不开（[#1](https://github.com/AstralMemory/RevoHelper/issues/1)）。
- 关闭开机自启时，启动任务其实已经删除，却同样提示失败。开关仍显示开着，之后开机也不会再自动启动。
- 原因是读取任务计划程序时，把“还没有启动任务”当成了读取失败。现在没有任务就直接创建，关闭时也能确认已删除。
  - 如果旧版曾提示读取启动项失败，开机自启可能已经失效：请手动打开 V1.0.9，在设置里重新开启一次“跟随 Windows 启动”。
- 水冷页的“登录前自动连接”没装过时，安装和检查状态也会因为同样的原因报错，一起修好了。
- 开着开机自启时把 RevoHelper 移到别的文件夹，5 分钟内开机自启会自动改为指向新位置。只改程序位置，任务计划程序里改过的延迟等设置都保留。

## 充电上限

- 改进关机时的保持处理。关机时已达上限，限充本应再保持最多 3 天，但 Windows 关机时，后台进程还没把保持写进固件就被结束了，关机后接着电仍会充电。现在后台进程收到关机通知后会先写完再回答 Windows，最多等 4 秒，不会出现“程序阻止关机”的提示。
- 关机被别的程序取消后，限充原来会显示为已关闭，固件却仍在保持，电池不会充电。现在开关保持打开，约 90 秒后电脑仍在运行，就自动接续限充；这期间关闭限充或换档，会先撤回这次保持。
- 刚关闭限充就关机时，按你的关闭处理，恢复正常充电，不会改成保持 3 天。
- 程序开着时把 RevoHelper.exe 挪到别的文件夹，限充会打不开，提示“系统找不到指定的文件”。现在每次都按程序当前的位置启动，移到回收站里的不会再用。
- 关闭限充后没能确认已恢复时，提示改为“固件计时到期后会自行恢复正常充电（通常约 30 分钟，最长 3 天）”。

## 退出官方控制台

- 改进唤醒后的托盘检测。开着“长期退出”时，原来只在 RevoHelper 启动时检查官方托盘。电脑从睡眠唤醒后，官方服务有时会重新打开托盘，托盘就会一直留着。现在唤醒后也会检查：3 分钟内每 10 秒一次，发现官方托盘就退出。唤醒后只退出托盘，你自己打开的官方窗口不受影响。
  - 检查期间电脑又睡眠，醒来后仍会检查；发现官方服务重新启动过，也会再检查托盘。
- 手动打开 RevoHelper 时官方服务还没启动，会在之后 3 分钟内检查托盘。
- 设置里“长期退出”的问号说明也相应更新。
