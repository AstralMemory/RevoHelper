# RevoHelper V1.0.1 Source Code

RevoHelper 是轻量、免费、开源的机械革命笔记本第三方控制台。开发与维护：Astral Memory。

## 构建

需要 Windows x64 与 .NET 10 SDK。运行发布后的程序仍需要 .NET 10 Desktop Runtime。

```powershell
dotnet restore RevoHelper.sln
dotnet build src/RevoHelper.App/RevoHelper.App.csproj -c Release
dotnet test RevoHelper.sln -c Release
dotnet publish src/RevoHelper.App/RevoHelper.App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o artifacts/publish
```

产物为 `artifacts/publish/RevoHelper.exe`。测试是离线自动验证，不替代具体机型实测。第三方声明和打包测试需要 PowerShell 7（`pwsh`）。

BootWater 的对应源码与嵌入产物均在包内。修改该组件后，先重新发布并复制到嵌入目录，再构建主程序：

```powershell
dotnet publish tools/RevoHelper.BootWater/RevoHelper.BootWater.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o artifacts/bootwater
Copy-Item artifacts/bootwater/RevoHelper.BootWater.exe packaging/BootWater/RevoHelper.BootWater.exe
```

本地生成运行包与源码包：

```powershell
pwsh -File packaging/Prepare-MaintenanceRelease.ps1 -PublishExe artifacts/publish/RevoHelper.exe -OutputDirectory artifacts/release-v1.0.1
```

输出目录必须是新目录或空目录。该命令只生成本地文件；不上传 GitHub、不启动程序或安装任务。

## 目录与边界

- `src`、`tests`：产品源码及测试。
- `tools/RevoHelper.BootWater`、`tools/RevoHelper.Probe`：组件和诊断工具源码；构建不需要运行诊断工具。
- `packaging`：打包入口、嵌入组件、第三方程序、许可和对应源码材料。
- `docs/release/V1.0.1.md`：本版更新日志；同目录其他带历史版本内容的材料保留其原版本用途。

本机 OEM 通信使用已安装官方服务的固定回环协议身份，不是个人账号、GitHub 密钥或云端凭据。相关接口基于兼容性研究，不代表厂商公开 API 或授权。主程序和 BootWater 使用独立角色，不能通过抢占主程序会话来掩盖连接失败。

源码包不包含本机用户设置、诊断日志、开发笔记、旧版本主页草稿、编译缓存或官方反编译材料。AMD 直连后端使用可选外部 RyzenAdj，包内只附说明。

项目采用 Vibe Coding 方式开发，代码主要由 AI 辅助编写；开发者负责产品逻辑、方案审批、UI、实测与迭代。
