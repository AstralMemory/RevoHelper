# RevoHelper V1.0.2

本次为V1.0.2正式版，产品版本 `1.0.2+20261030`、文件版本 `1.0.2.4`。运行包与源码包由本地明确清单生成，不自动发布GitHub；不以打包替代实机验证。

## 充电上限

- 使用开关和60% / 80% / 100%三档刻度条。60%与80%已得到开发者本机实测反馈；其他机型不能直接沿用结论。
- 100%先解除已有实验覆盖并确认恢复，然后按原生策略充电，不将100写入固件限充阈值。开关仍开启表示可以继续选档；关闭开关则完全退出本功能。
- 切换或应用可能需要15–30秒。状态未确认前不把阈值回读等同于实际停充；不主动将电池放电至目标值。
- 长说明改为圆问号悬停提示；常驻红色延迟说明保留。恢复待确认时仍显示恢复操作，并阻止继续接管。
- 开关直接操作，不显示启用确认弹窗；副作用与机型说明保留在问号中。
- 修正X隐藏到托盘时误停限充：最小化、托盘隐藏与普通界面操作不中断已开启会话，真正退出仍恢复原值。
- 移除普通性能/风扇与CPU/GPU调整前一律停限充的耦合；仍保留忙碌/待恢复限制，真实平台或阈值被外部修改时安全停止，不反复抢写。
- 增加仅本进程有效的电源暂停意图：成功手动开启后，拔电/睡眠先暂停并恢复原值；重接/唤醒后确认旧会话恢复与稳定AC，再尝试恢复当前选择。暂停时逻辑开关开启不表示硬件仍在限充。
- 手动关闭、手动恢复、真正退出或健康失败清除恢复意图；恢复未确认不自动启用，失败不无限重试，正常重新启动仍默认关闭。
- 60% / 80%目前仍通过共享平台状态实现，可能影响其他固件分支。没有发现此代码改动充电电压/电流或关闭电池保护，但这不是零风险或全部副作用可恢复的证明。固件可能自行保存设置，长期与异常掉电行为尚未验证。

## 电源与水冷

- Windows电源模式跟随的长说明改为圆问号悬停提示，避免遮挡开关。
- 水冷转速区移至页面前部；智慧控制使用独立开关，四档手动滑条在智慧控制开启时禁用，关闭后恢复上次手动档。
- 键盘灯光只保留分区编辑器内的单一电源开关，移除早期重复入口；保持普通背光与详细RGB通道的兼容处理。
- 本次会话中曾确认连接的水冷设备意外断开后，保留10分钟的同设备恢复机会；每次至少间隔3秒，异步等待、不持续扫描蓝牙、连接请求不并发。
- 用户主动断开、选择其他设备、注水/重置或退出会取消对应恢复机会；不会自动选择陌生设备。

正式版名称不扩大硬件支持范围。电池覆盖默认关闭，不保存跨进程自动启用状态；完整跨阈值、长期及异常掉电行为尚未全部验证。
